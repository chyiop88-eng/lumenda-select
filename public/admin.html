網站管理後台

網站現只接受 SK-II 神仙水及小燈泡兩款明星產品訂單。登入後可管理訂單、匯出 CSV、上傳及更換兩張廣告圖。Session 最長 8 小時。

管理員登入

配送規則：經確認商品小計滿 HK$4,000 免運費；未滿 HK$4,000 按目的地報運費及適用稅費。免運不等於免稅；所有價格及免運資格均待人工核實。

廣告圖管理

支援 JPG、PNG、WebP；每張最多 4 MB。上傳成功後首頁會直接使用新圖。

🎬 影片／動態圖片管理

預留三個位置：首頁品牌影片、神仙水影片、小燈泡影片。可以選 MP4 / WebM 直鏈、YouTube、Vimeo，或者 GIF / Animated WebP / APNG 動態圖片。未設定或者未啟用就唔會顯示、亦唔會留空白。

先將影片上載到 YouTube、Vimeo 或外部影片儲存／CDN，再將 HTTPS 連結貼入後台。Render 免費網站唔適合直接保存大量影片；今版儲存嘅係影片連結而唔係影片檔案。

代理／介紹人邀請連結

建立專屬連結後，交俾下線代理或介紹人分享。有人經連結提交訂單，系統會記錄所屬邀請碼。呢啲連結唔係管理員登入連結，代理亦睇唔到客戶資料。

目前只統計經專屬連結送出嘅訂單數量；唔會自動計算佣金、收款或者向代理公開客戶資料。停用連結後，已有訂單歸屬仍會保留。

📇 客戶電話通訊錄／記憶

只整理客人已正式提交並同意處理嘅訂單聯絡電話。可按電話或姓名搜尋；不會記錄未送出嘅輸入。客戶名單只限管理員查看，唔作自動廣告或群發。

🤖 訂單 Bot／Stripe 安全付款

網站客服先用安全規則回覆，並為每張新訂單提供私人進度連結。你日後喺 Render Environment 加 `XAI_API_KEY`、設 `XAI_BOT_ENABLED=true`，先會試用 Grok API（第三方用量可能收費）。

線上付款：你可喺每張訂單填入實際港幣報價，再提供商戶自己建立嘅 Stripe／PayPal 付款連結。唔會單靠網址回傳或者客人截圖就自動當已付款，需要喺服務商後台核實。

Stripe 正式卡付款流程需由商戶本人設定私密 API Key、Webhook Signing Secret 同公開 HTTPS 網址；未完成前不會自動扣款。Stripe 簽名 Webhook 核實後會自動顯示已付款；手動貼出嘅 PayPal／Stripe 連結則維持人工核對。產品金額由伺服器按單價與數量重算，不得隨便覆寫。

價格：神仙水 HK$899／支，約 US$114.55（2026-10-12 參考匯率）。小燈泡價格仍待確認；HK$4,000 免運門檻由正式港幣商品小計計算，稅費照實際目的地另報。
